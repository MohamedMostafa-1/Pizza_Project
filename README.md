## 📌 About The Project

**Pizza Project** is a simple Pizza Ordering System built with **C# and Windows Forms**.

The application allows users to customize their pizza by selecting the size, crust type, toppings, where they want to eat, and then calculates the total price automatically.

## ✨ Features

- 🍕 **Pizza Size**
  - Small
  - Medium
  - Large

- 🥖 **Crust Type**
  - Thin Crust
  - Thick Crust

- 🧀 **Toppings**
  - Cheese
  - Mushrooms
  - Olives
  - etc.

- 📍 **Where to Eat**
  - Eat In
  - Take Out

- 💰 **Total Price**
  - Automatically calculates the total price based on the selected options.

## 🛠️ Technologies

- C#
- .NET
- Windows Forms
- Visual Studio
